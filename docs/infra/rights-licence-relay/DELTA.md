# rights-licence-relay delta

Infra item rights-licence-relay (acting DRI, 2026-10-15 21:45Z): it ends the D1 exception the DRI granted rd-9
(`manage-agents/reviews/rd-9-dri-signatures-20261015.md` item 2). Lean returns every narrowing mechanism's licence

Lean returns to a slot the request fixes (R8(b) row binding, row 2).

base and head (before the sync with main against d7ea7228b, after it against 8bc65a907) for the 25 genuine rights sources of `tests/test_relay_binding_inventory.py`
([`evidence/user-visible-answers.json`](evidence/user-visible-answers.json)). The scope answer, whose narrowings
the rights report shows, keeps its shape and values.

## Trust ties pass (row 7; infra item ties-rights-licence-relay, 2026-10-17)

Method. `tools/trust_map.py` was run against row 4's base (`f3046f7dc`, main's first parent before this item's merge)
and on main with the item merged (`85b20fcba`). Every untied D[V] or G[V] declaration whose lines the item added or
grew (V +102 in all) was looked up in `lean/statements.txt` for a theorem whose `-- uses` line names it and another
anchor. The tool accepts any such theorem. A tie was added only where the statement fixes what the declaration means.
Only `VE.Rights.Ground` is named by any dumped theorem. The encoder theorems of `lean/ResponseShape/Encoders/Rights.lean`
(`elaborate_fits`, `groundJson_fits`) cannot tie anything, for two reasons. First, the statement dump reads
`lean/VE/Audit.lean` only, and it holds no `ResponseShape` theorem. Second, they read the generated JSON through `skel%`
rather than the `Shape` declarations, and `Fits` constrains an answer's form, not its meaning.
