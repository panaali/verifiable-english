# dr-sc-readingset-ids DELTA: the reading-set id rebuild step under `scope@0`, and its situation bases

Feature item dr-sc-readingset-ids (scope family; gap LP-20261031T1358-5). Base: main at 1edb74de2. Only the pilot tool
`tools/readings_s1_pilot.py --rebuild-reading-ids` changes; no service mode, no Lean file and no checker answer
changes. The DRI decided rows 1 and 2 (`reviews/dri-decisions-20261101-dr-sc-readingset-ids.md`) and, in fix round 1
(review F1), row 3 and row 2's no-frame case (`reviews/dri-decisions-20261102-dr-sc-readingset-ids.md`). The only
other file changed is `ve/document`'s check, which takes the text to check in place of the file's (`raw`).
