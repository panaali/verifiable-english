**The proof.** Under a choice, `govern` answers `patch` (a governed set needs a governor). So both sides are the
document with `units` and `reading_sets` written. `setObjVal_swap`/`setObjVal_twice` (sc-5rd's scratch tree lemmas,
with `T` and `repl` inlined so no new `def` is added) line up the two writes. The sets agree by `filter_pair`, since a
governed set leaves. A unit outside the governed set units is `o₀`'s on both sides, by `assemble`'s unit check
(`assemble_units`). A governed unit `y`: with distinct ids, `contentOf o (idOf y)` is `y`'s own row (`find?_idOf`).
`assemble_ok` now says a reading's content equals the content of every choice that picks it. When the pick has no
content, the unit is no rule, so `govern` leaves it (`govern_preserves`). `governSets_ok` now gives every checked choice
its answer in `outs` (from `faultOf = none`). `unitsOf_atChoiceOn` takes the top-level `WF` it uses instead of
`JsonWF`, as the answer `out` has it.
