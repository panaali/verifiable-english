## Choices the prereg fixed where the plan left room

Each is in the prereg, before the calls. The reader of PS-2a should check them.

1. **Mapping:** role definite to `definite`; heading noun phrase to `plural` (S23's shape; every heading item is a possessive plural).
2. **Rule-guard (b) wording.** The plan reads "(for a rule: this rule decides nothing here)"; spec 2.5 names only rule-act items. The prereg follows the plan for both rule cells. This is a difference between the two documents, not resolved here: the guard cells were read with the rule wording.
3. **Rule items are computed at formula level**, on `∀agent (guard → act)`, because `Rules.lean` (spec 4.5) is not merged.
4. **Proviso.** Three pairs, one per row. A proviso item's situation has the projected goal true and `f.close pre` false, because the plan's "where the projected goal fails" cannot separate the two goals. `unconditional` does not enter a `one_reading` or `no_carrier` cell. So `generic`'s bar (met) added nothing: its consequent cell is one-reading, and the results note it.
5. **Disagreeing classes:** union; one-reading needs every class; one no-carrier class empties the row's cell. In this run the classes disagreed on no cell's candidates.
6. **`cellOk`.** Assumed over asserted (spec C3's proposal, its Q1 not ruled); never triggered: asserted got 0 answers on every target item.
7. **Controls.** No (e) by the cell rule, so the key is (a) where the sentence as written is false and (b) where the filter leaves the trigger unreached (`base` in the stub table).
8. **Outage retries:** a call that never reached the model is retried, at most three attempts. None occurred: `attempts` is 1 on all 4,320 records.
