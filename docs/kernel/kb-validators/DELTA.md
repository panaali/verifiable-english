# kb-validators: user-visible delta

Feature item kb-validators (architect seat, round 4, decision D13; `manage-agents/prompts/task-kb-validators.txt`).
The `metered` mode checks the norms profile of its model itself. Through every public entry nothing changes:
Python builds a model before it evaluates in it, and the model is refused there, on main and here, with the
same text. The five frozen keys' answers are unchanged (REPORT.md, "Acceptance").
