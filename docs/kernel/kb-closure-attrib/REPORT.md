## How the charge works now (and where it differs from the task's wording)

- **Codeless auxiliaries only.** The task lists `match_<n>`, `_unary`, `proof_<n>`, `eq_<n>`, `splitter`. The tool attributes only auxiliaries that hold none of `f`'s code: a matcher (`Meta.isMatcherCore`), a matcher's `splitter`, `proof_<n>`, `eq_<n>` (`codeless`). `f._unary` and `f._mutual` hold `f`'s body: whoever reaches them runs `f`'s code, so they keep `f`'s range (found: `VE.Time.Wire.elabTerm.addTerm._mutual`, reached from `elabTerm`; fixture `oddFixture`/`evenFixture`). The conservative choice; it can only charge more than the task's literal list.
- **A mutual block counts as one.** Structural mutual recursion compiles `sizeT` with `sizeL`'s body and `sizeL.match_1` without naming `sizeL` (probe on Lean's output; fixture `sizeFixture`). Reaching any member of a block (`ConstantInfo.all`) counts as reaching each member, so their matchers keep their ranges. Without this the first measurement undercounted by 12 kernel lines (9,954).
- **"Reached" is "charged anyway".** `chargedUsers`: the user names of the constants reached, their mutual blocks, and the prefix of every non-codeless auxiliary reached.
- **A root keeps its prefix's range** (a run whose root is itself an auxiliary has no user to charge; the existing `splitter` test keeps passing).
- **`--why` agrees** with the measure (`whyChains` skips attributed auxiliaries; `test_a_matcher_reused_from_an_unreached_declaration_is_charged_to_its_user` asserts no chain to `reuseF`). The census (`census`) is not a closure and is unchanged.
- **The tool's own fixtures are counted** in the module `_stdin` (`countedModule`: the file run has no module index); no registry path reaches them; the census still skips them.
