# cmp-s3-cfr-1b: user-visible deltas

With the profile off, nothing changes: `clauses-elaborate` refuses K10 with cmp-s3-cfr-1's text (pinned in
tests/test_right_clauses.py::test_right_clauses_differential and RunExamples.lean), and cmp-s3-cfr-1's profile-off
