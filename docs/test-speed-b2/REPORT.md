# Test speed batch B2

## Delivered

`LeanService.exchange` emits each validated service mode to the coverage recorder. Map version 7 stores those mode edges. The selector narrows recorded `ve_service` users for a changed Lean module by following the compiled dependencies of the `runMode` dispatch equations. The dependency table is generated by Lean in `tools/lean_mode_deps.lean`; Python checks its source hashes and uses it only for test selection. Other Lean executable users remain selected. Unknown modes, users without a recorded mode, a missing or stale table, unreadable imports, and changes to Protocol or Serve select every service user. Tests that read `checkers.lock` remain selected on a pin change. The nightly and release gates still run the full suite.

No VE verdict, diagnostic, wire field, theorem statement, or accepted input changes. This batch changes developer test selection. No product-visible delta invokes a DRI standing ruling or needs a new DRI signature.
