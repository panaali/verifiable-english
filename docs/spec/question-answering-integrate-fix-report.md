## Spec deviations, each recorded

1. **`gaps` drops an offset past the rest.** Spec 2 allows a body change made to prove a reviewed statement;
   `mapSpan_valid` needs `g ≤ rest.utf8ByteSize`, which the lexer gives but no lemma states. Recorded in spec 2.2.
   No fixture changed.
2. **`one` carries `text` (the A0 line).** Spec 8 lists `form`, `sentence`, `ast`, `spans`; the line is added so no
   Python writes English (plan 5: the CLI prints Lean's lines). It is in the exported field table.
3. **The export case** `{"id", "export": "codes"}` is new: it is how the relay holds no table of its own
   (checklist line 1). An export with any other value or field is an error row (`test_the_export_case_is_exact`).
4. **The row schema leaves the result to the relay**, as E2's English modes do; `tests/test_route_row_schemas.py`
   requires every described answer object to be closed, and the relay checks the result field by field against
   the producer's exported table.
5. **The case requires `source` = `question`, authoring mode and cap 2**, so the six E2 identities are the ones
   `english.read` gives for the same text (`test_a_case_that_does_not_bind_its_question_is_refused`).
