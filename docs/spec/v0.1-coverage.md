## Evidence and counting convention

The fixed 210-item sample has 30 items per dataset. Inputs are `experiments/E0/second_rater.jsonl`, `second_rater_metrics.json`, `second_rater_adjudications.jsonl`, and `survey_samples/_drawn/{dataset}.json` at the pinned commit. The construct lists are `roadmap_independent` and `roadmap_proposed_adjudicated` in the metrics file. Recover any input using `git show 46be9e1bafc85e37456cbf56e9dc92b6c8178666:experiments/E0/<path>`. No first-rater labels enter this projection.

All moves below are authored expressibility judgments, with translation sketches, not parsed v0.1 witnesses, proved translations, or source-engine differential results. Keep source helper expansions, defaults, exceptions and complete item units from SECOND_RATER.md. Reified means explicit tuple/position/snapshot encodings with functional field and domain correspondence obligations; an unexplained interpreted predicate is never sufficient. In particular, adapters must expose data rather than precompute the missing logical property.

`D` means projected DIRECT under the selected profile; `R` means projected REIFIED; `-` means no new fit. Existing DIRECT/REIFIED items remain unchanged, except in the separately displayed proposed-adjudication baseline. A declaration of arbitrary JSON or real-valued inputs cannot be silently narrowed to integers. Gatekeeper projections concern the source Kubernetes/template schemas and retain missing values and permitted alternative types; arbitrary out-of-schema Rego inputs need a separate audit.

### Borderline translations and source checks

- `horizontalpodautoscaler`: `(max - min) >= spread` translates to `add(min, spread) <= max`. The source `minimumReplicaSpread` parameter is an integer field, not a compile-time numeral; specializing it to a chosen deployment would change the counted item.
- `online_max`: preserve the exact two implication postconditions, even if surprising. The array adapter supplies ordered positions, the final position, and index-to-cell correspondence; neither replacing Length-1 by this structural endpoint nor checking it assumes an arbitrary numeric max oracle.
- `is_even` and `even_list`: `x % 2 = 0` iff `exists q, x=2q` for mathematical integers. Preserve Boolean equivalence, output sequence ordering, membership and all loop invariants; do not strengthen the filtering contract to a multiset equality it does not state.
- `poddisruptionbudget`: Kubernetes permits integer-or-string availability fields. Preserve type tags: for the source Rego comparison, a string maxUnavailable compares above numeric zero, while numeric replicas do not compare above a string minAvailable. These branches need a primitive type tag, not parsing percentages or evaluating their intended Kubernetes percentage meaning. Missing values still default to 1/-1. [OPA comparison implementation](https://raw.githubusercontent.com/open-policy-agent/opa/main/v1/ast/compare.go) places Number below String. This is a translation obligation to pin against the deployment OPA version, not a claim that the policy enforces its diagnostic prose.
- FRET source variable metadata declares e.g. `kias`, `kgs`, `TurnKnob`, `vehAirPress`, `roll_angle`, and `pitch_command_acceleration` as `double`. The second rater interprets their requirements as real-valued signal formulas; neither that interpretation nor floating-point execution is faithfully replaced by standard integers. Even apparently integer-valued thresholds such as 30.0 do not discretize their signals.
