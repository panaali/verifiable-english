## Notes for the DRI

1. **Connective notation.** answer-key.json's `source` field says the copy writes `&` for `∧` and `|` for `∨`, and
   the C6, C-doc and A-*/SUF cells do so. As the task and the decision require, the six repaired cells use section
   6.2's `∧` verbatim. Both run scripts and `reference.py` read either form, and the transcriber compares both. So
   the file now mixes the two notations. That changes no answer, and I did not normalise it.

   `COVERED:QUARTERLY_UPDATE`) are the transcriber's names. Section 6 gives only the two verdicts in order, so the
   test checks the values in order and not the labels.
3. **Section-5 fields.** The `dates`, `quantities` and `years` fields are section-5 situation data, not section-6
   cells. The new test allows them and does not compare them. `test_transcription_is_pinned` and the cases.json
   tests cover them.
4. **The stale M3 copy in main's results.json** (step 5) was fixed by this rerun. Before this branch, `run.py
   --check` on main would have reported results.json out of date.
