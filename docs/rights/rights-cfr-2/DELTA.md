# rights-cfr-2 (and rights-cfr-3): user-visible deltas

Base 33fe04615107. A request without the new optional `located` and `situation` fields gets the same answer as on
the base, except row 1's line and the added fields in rows 2-4. Unknown case keys were ignored on the base
(`Route.Run.caseKind` reads only `kind`), so no request the base refused is now accepted.
