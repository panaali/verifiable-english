# AR-2 deltas

AR-2 changes how Lean sources are pinned, nothing they compute. No Lean source (`.lean`) and no `ve/**/*.py` file
changes, so no verdict, diagnostic, wire field, document-check CPU or trust count changes: `tools/trust_map.py
--since f98183bf` reports K +0, S +0, D +0, G +0, tied +0, trusted +0 (`evidence/checks.json`). The rows below are
changes to repository tooling. None is a user-visible delta of the checker. The removed checks are the ones
decision D2 removes; the DRI adopted D2 on 2026-10-10 (`arch-dri-decisions.md`, standing ruling R11).

| Change | Kind | Ruling |
|---|---|---|
| `lean/VE/Route/frozen-sources.sha256` lists 28 files, not 408: the 25 with K declarations in `tools/trust-classes.json` and the three `ve.core@0.1` decoders (`VE/CertificateWire.lean`, `VE/Json.lean`, `VE/Order/Wire.lean`; `DECODERS` in `frozen.py`). It is generated by `frozen.py --write` and carries a two-line header (`evidence/freeze.json`) | generated inventory narrowed by D2 | SIGNED by standing ruling R11 (DRI-RULINGS.md): D2 |

Tests: `tests/test_frozen_sources.py`, `tests/test_precommit_hook.py::test_frozen_guard_*` | check narrowed to D2's list.
