# Q1.4b: DELTA

Base: `parse_speech` at the merge base `de7cb4022` ([evidence/base.json.gz](evidence/base.json.gz)); head: the same
corpus with every `Is ` wording read by Lean's question reader for the speech-acts caller
([evidence/head.json.gz](evidence/head.json.gz)). The corpus starts with Q1.4's 2,436 records
(`../q1-4/evidence/speech_ab.py write`); earlier rounds' `evidence/speech_ab_f2.py augment` added 2,295 (a declared
negative verbalisation, names with a digit or underscore, `reader_cases`, one sentence per grammar rule), and fix
round 5 (DRI note 2026-10-28c) added 314,303, so the corpus asks every word each environment declares in every place
(`opening_cases`): in every environment the evidence asks in (Q1.4's `speech`, `glossed`, `f0-reviewed`, `f0-checked`
and the added `negative`, `names`, `unverbalised`), each rule of the grammar source
`ve/english_grammar/relational-fol@0.json` in its shortest sentence, its slots spelled from `vocabulary` (every
constant bare and quoted, every sort's nouns, every one-place predicate's positive and not-form, every sort's label)
and the grammar's closed classes (markers, list markers, articles, counts, relative pronouns): every slot with each
word on its own and every two slots with every pair of words (a pairwise covering; the full product is about 22
million sentences); each rule's first sentence in each case and spacing variant (every sentence of the
`<name> <form>` rule the base reads); and each rule's sentence in each formula place of every rule, each asked with
the auxiliary taken out of each gap that has it. `speech_ab_f2.py audit evidence/delta.json` (and `check`, the same
check) exits 1 unless `coverage` finds every such question recorded, naming what is not. The recordings differ in
6,646 `verdict`, 266,505 `class`, 7,044 `wording` and 0 `lint` rows across 319,034 records;
[evidence/delta.json](evidence/delta.json) lists the verdict and lint rows with the counts, and the audit recomputes
every row from the two recordings and checks delta.json against them. It exits 0: every verdict row is in exactly one
signed class with its recorded count (V1-V19: 2026-10-27 item 4; P1-P19: reviews/dri-decisions-20261028-q1-4b.md
items 1-4; P20-P109, class (d), 6,608 rows grouped by the axis that asked them and their rule:
reviews/dri-decisions-20261028-q1-4b.md item 5, generated by `speech_ab_f2.py delta-md evidence/delta.json 20`), and
every refusal row keeps each name the base quoted and a span wherever the base had one (R1 (a), (b)) or is R2's rule
O1. Class (d)'s condition test compares the speech caller with `ve ask` on the wording the speech caller reads:
`wording_text` trims the space around every unit wording (unchanged here) and `ve ask` does not; the 2,760 rows with
space around them are compared trimmed, signed by reviews/dri-decisions-20261028-q1-4b-b.md item 2, and each P row
that holds one says so in its Ruling cell. Class (d) outside the base's acceptance set is closed by structure (item 1 of
that file): `in_base_set` states the set, `check` fails on a base reading outside it and `coverage` asks every member
shape, and the relay and differential tests cover every head reading outside it. No `lint` row: the
`OpaqueWording` warning is gone only where its question is now refused (rows V1-V10).
