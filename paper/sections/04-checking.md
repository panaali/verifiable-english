## Finite evaluation and countermodels

A finite model explicitly enumerates each domain, constant denotation, and
predicate relation, with a completeness attestation. Within that model, an
absent tuple is false. A missing relation entry is invalid input. This local
closed-world convention says nothing about whether the inventory describes all
relevant real objects. Evaluation returns satisfaction, violation, or a resource
outcome. Explanations can expose witness bindings and vacuous truth; a skipped
branch is not evidence about that branch.

A countermodel satisfies every premise and falsifies the exact conclusion.
The public witness checker validates the model and reevaluates the formulas.
Such a witness refutes the inference, not necessarily the conclusion in the
world. Search enumerates finite domains, constant aliases, and extensions of
used predicates within budgets. Failure to find a witness remains inconclusive.
This is not just a small-bound limitation: base FOL can describe satisfiable
premises with only infinite models, as the repository's strict transitive
successor example illustrates.

## Tableau certificates and replay

Proof search starts with the premises signed true and the conclusion signed
false. Certificates contain data-only expansion and close instructions, bound
to the expected environment, ordered premises, and conclusion. Replay derives
the rule from the selected signed formula and reconstructs its children. The
certificate cannot submit replacement child formulas or an alternative theorem.
A branching rule requires every child to close.

Existential-style rules introduce fresh, sorted witness parameters. Universal-style
rules instantiate only with a declared constant or an existing witness of the
required sort. They cannot manufacture an inhabitant for an empty sort. Equality
closure respects aliases and substitution. The current base checker also
recognizes opposite-signed compound formulas with identical parameter bindings.
Search priorities and normal-form hints do not become trusted inference rules.

The Python API replays certificates in Python. An optional Lean executable
accepts base-profile queries and invokes the proved checker on decoded ASTs.
Successful process exit alone is insufficient; its response must accept the
certificate. Closure-profile replay in this checkout uses Python expansions and
is explicitly rejected by the Lean certificate adapter.

## Claim graphs and conditional conclusions

Claims bind their exact source and AST under a shared environment. A deduction
names ordered premises and an exact conclusion. The Python graph checker rejects
cycles, unresolved references, stale bindings, and conflicting aliases. Checked
positive edges compose into a root implication with every used undischarged leaf.
An uncertified intermediate claim remains an unresolved obligation. Evidence
assessments neither remove assumptions nor turn a conditional proof into approval.

| Finding | Required evidence | Interpretation |
|---|---|---|
| `follows` | Replayed certificate | Premises entail the conclusion. |
| `refuted` | Certificate for the negation | Premises entail its negation. |
| `gap` | Checked finite countermodel | This inference is invalid. |
| unresolved | No accepted finding | Entailment remains unsettled. |

Both `follows` and `refuted` can arise from inconsistent premises and must remain
visible. A `follows` certificate and a valid `gap` witness for the same edge are
instead a checker conflict: the witness satisfies the premises. The implementation
withholds successful composition in these cases. Neither a proof badge nor a
matching evidence-scope string authenticates a record or proves its relevance.

## Semantic comparison and attack validation

The equivalence oracle returns `EQUIVALENT` only with replayed entailments in
both directions, `DIFFERENT` with an independently checked distinguishing model,
and `UNKNOWN` otherwise. One distinguishing model establishes difference but
may not establish which formula is weaker. Strict weakening additionally needs
proof of the forward implication and a countermodel to the reverse implication.

Reference validation seeks a nonvacuous satisfying model and a falsifying model.
Attack validation rejects alpha-identical and certified equivalent candidates,
stores witnesses, and retains uncertain classifications. Its guard-coverage
criterion is explicitly syntax-sensitive. It is not a semantic guarantee of
relevance under arbitrary equivalent rewrites. Differences confined to empty
sorts may be annotated only when conditional certificates establish equivalence
under explicit nonemptiness premises; bounded search absence does not suffice.

`UNKNOWN` is an uncertainty category, never a synonym for false, invalid, or
wrong. Experimental reports must retain its denominator and give both extreme
assignments when estimating correctness. Validation attrition must be reported
separately from judge failures. Quantifier structure and resource settings must
be reported because they affect oracle coverage. The implemented bounded search
is incomplete even on the syntactic two-variable fragment.
