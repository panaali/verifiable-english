# E4: uptake of checker feedback

E4 compares prose critique, an unchecked countermodel assertion by a dishonest
critic, and a checked-feedback arm. All display the same complete hypothetical
finite interpretation. On invalid inferences it is a genuine countermodel;
on valid siblings it fails replay. The scored inventory has 120 inferences,
half valid, from 12 templates and five vocabularies. Each judge receives all
three arms, for 360 trials. Neither 7B nor 14B passed the original development
gate (prose FA 20--60%, HA at least 70%, parseability at least 90%); the runs
were explicitly retained as pilots.

The checked arm reveals the label-defining finding. The exact string-building
lines in `experiments/E2E4/e4.py`, function `matched_critiques`, are:

```python
formal = ("Checker replay of the critic's interpretation: " + status + ". "
          "Logical inference finding: " + ", ".join(check["result"]["findings"]["step"]) + ". "
          "Premise truth values: " + json.dumps(list(model_check.premise_values)) + ". "
          "Conclusion truth value: " + json.dumps(model_check.conclusion_value) + ". "
          "Complete interpretation: " + json.dumps(asserted, sort_keys=True, indent=1))
```

The finding is `follows` or `gap`. Certificates and countermodels establish
the labels during Python replay; the prompt displays the resulting finding,
not a certificate for the judge to verify. Consequently, E4 measures uptake
of an explicit answer-bearing checker signal. It does not isolate
countermodel understanding, independent reasoning, or English rendering.
Critiques are padded to equal whitespace-token length, which does not equalize
model-token lengths or informational content. No forged-checker control was run.

## Post hoc lenient parsing as the presented analysis

The **POST HOC** presented rule takes the last valid approve/reject JSON object
anywhere in a reply, allowing trailing text. All assigned replies then yield a
verdict. Protocol failures under the original stricter rule remain separate,
with no missing denominator or discarded response.

For 14B, the post hoc checked-minus-prose FA contrast is -.117 with descriptive
95% template-t interval [-.231, -.002]; HA changes by +.083 [-.017, +.184].
The unchanged frozen strict-parser rule gave FA -.267 [-.392, -.142] and
HA +.150 [.027, .273], satisfying its protection criterion. Nine of those
16 strict-parser prose false approvals are recoverable rejections. Thus more
than half of that apparent reduction comes from differential protocol failures.
Worst-case scoring is conservative within a cell but not necessarily for a
between-cell contrast.

For 7B, prose rejects 56/60 valid inferences; checked feedback increases HA
from 4/60 to 52/60, while both arms have zero false approvals. This is recovery
from near-indiscriminate rejection, not a demonstrated FA reduction. The
post hoc random sample of ten prose replies is printed with each prompt's
opening and final instruction in the appendix (seed 20260921). All ten say
only `{"verdict":"reject"}`. Indeed, all 360 7B replies contain seven tokens.
The prompt opens "Decide whether the inference is valid" but ends "Return
exactly one JSON object: {\"verdict\":\"approve\"} or
{\"verdict\":\"reject\"}." It does not repeat whether approval concerns
the inference or critic. Verdict-only replies cannot resolve what the judge
was reacting to; ambiguity is a plausible explanation to test, not a diagnosed
internal mechanism. Neither judge supplies evidence of family-general efficacy.
