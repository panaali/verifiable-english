# Question-answering fixtures

`group.ve.md` is generated by `build_group.py` from the three sentences and
vocabulary fixed in `docs/spec/question-answering.md` §7.1. The generated
source spans are byte offsets in the source outside the fences.

`udhr-part07.ve.md` is an unchanged copy of
`manage-agents/pilots/udhr/run-20261008T1800Z/translation-part07.ve.md`.
Its source SHA-256 is
`4f4e8c19c66c8232e8e34e03b53897974e5d8679b0adeef78a2fc5f1e2b825dd`.
The pilot run ID is `run-20261008T1800Z`; its review and open terms travel with
the copied front matter. The copy is an acceptance fixture, not a new reading
of the Universal Declaration.

`agent-policy/build.py` generates the four A documents from the committed
policy, its m1 exception-list variant, the original log inventory and the
five selected action records. It reads each selected log sentence with the
existing one-reading English reader before storing its AST. The `a-deny`
document uses `environment.deny-neednot.json`: the plan names the flag-free
`environment.lean.json`, but that file omits the functional and total
declaration of `tool` needed to read the original rule and record wording.
The full environment has the same deny/deny defaults. The norm contents come
from the existing norm-English parser, including each rule's sign and guard.
