# Generator provenance

Anchor: Qi et al., *Large Language Models Meet Symbolic Provers for Logical Reasoning Evaluation*, ICLR 2025, https://openreview.net/forum?id=C25SgeXWjE ; public source https://github.com/opendatalab/ProverGen at `1d8abd227912cee0b24819eb373ceba80979cb49` (inspected 2026-09-22).

The public repository was cloned and its `logic_skeleton_generator.py`, `utils/logic_generator/generator.py`, `rule_generator.py`, `prover9_interface.py`, and `data/rules.json` read. No public test or training item was reused. `provergen_rules.json` preserves the upstream nine normal-rule and fourteen goal-rule templates verbatim. The repository README does not supply a clear overall code license; no upstream implementation files are redistributed here. Resolve upstream licensing before broader redistribution of its rule data.

Installation is impractical for this task: upstream requests Python 3.8 and NumPy 1.24.4 (this worktree uses Python 3.14); it requires an external, old Prover9 binary that is not installed and a further LLM translation stage. We implement the same backward skeleton construction locally without paid generation calls or incompatible dependencies.

Preserved mechanisms: 75% atomic versus 25% rule goals; three truth values; hard-mode random conclusion position; the exact rule pools; complete local requirement-table enumeration; randomly expand a pending fact; stop and directly provide a fact with probability 0.4 when at least two other facts remain; 6–9 expansion depths; Uncertain distractor generation requiring the distractor rule to follow from the other known values; omit Uncertain facts; reverse-order reasoning steps. For the <=3-proposition local rule stage, exhaustive Boolean assignments exactly replace Prover9's quantified independent-unary-atom checks over a nonempty domain. Empty/inconsistent local model sets are rejected rather than labeled Uncertain.

Declared differences: Python Random replaces NumPy sampling (seed does not reproduce upstream bytes); a bounded 200-attempt local-rule search replaces upstream's 50-attempt return/resample behavior; class balance fixed at 20/20/20; globally fresh distractor atom IDs avoid accidental cross-rule collisions; sampled predicate substitutions introduce closed unary/binary and nested-quantifier formulas with independent predicate namespaces; deterministic compositional English replaces the upstream LLM translation and augmentation stages. Atoms are built from known predicate glosses, so lexical discovery is limited. It is a faithful adaptation of the symbolic generator, not the full ProverGen language pipeline or dataset distribution. Report expansion depth, not independently measured shortest proof length.

Gold label validation uses an independent Tseitin-CNF/DPLL solver on the skeleton. Every satisfiable query polarity is realized as a two-person VE finite model by making each fresh relation full or empty. VE evaluates all gold premises and the query on these witnesses. Because each atom has a disjoint predicate and the two-person domain realizes either truth value, this validates the substitution's independence; UNSAT of a propositional polarity transfers to the substituted FOL formulas. Both directions have witnesses for every Uncertain item. E0 `folio_formula_flags` checks every rendered FOL formula; actual VE AST construction/type checking and strict parse/print roundtrips add stronger validation. No finite-search exhaustion is used as a gold label.
