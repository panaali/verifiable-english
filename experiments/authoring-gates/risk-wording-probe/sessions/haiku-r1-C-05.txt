Read each short text and answer its question from the text alone. Choose one option and give a one-sentence reason.

Text 1

The actions available to the agent are emptying the cache and doing nothing.
Rule 1. Every action must not be performed, if that action might lead to a server outage, unless the user has confirmed that action.
Emptying the cache cannot lead to data loss.
Rule 2. Every action may be performed, if the user has confirmed that action.

According to the text, if the agent empties the cache, can data loss happen?
(a) The text does not say.
(b) It can, but the policy forbids the agent to let it happen.
(c) No: the text rules out data loss when the agent empties the cache.
(d) It can, unless the user has confirmed emptying the cache.

Text 2

The actions available to the clinic are giving the patient drug A and giving the patient drug B. Giving drug A allows a rash to happen.

What does the last sentence tell you?
(a) The clinic is permitted to let a rash happen when it gives drug A.
(b) Giving drug A leads to a rash in every case the text allows, and giving drug B avoids a rash in every case the text allows.
(c) Giving drug A leads to a rash in every case the text allows, and giving drug B avoids a rash in at least one case the text allows.
(d) The text does not say.

Text 3

A delivery robot can take the lift or take the stairs. Taking the stairs might lead to a fall. Taking the lift certainly leads to a fall.

The robot takes the lift. What does the text tell you about a fall?
(a) A fall happens in every case the text allows.
(b) No fall happens: a robot is safe inside a lift.
(c) A fall usually happens, but not in every case.
(d) The text does not say.

Text 4

An agent can apply the database migration or do nothing. The duration of the migration is at least 5 minutes. The duration of the migration is at most 60 minutes. Applying the migration leads to a task delay exactly when the duration of the migration is greater than 30 minutes.

Which of these follows from the text?
(a) If the agent applies the migration, a task delay can happen only when the migration takes more than 30 minutes, but need not happen then.
(b) The text does not say.
(c) If the agent applies the migration, a task delay happens when the migration takes more than 30 minutes; the text does not say what happens when it takes 30 minutes or less.
(d) If the agent applies the migration, a task delay happens when the migration takes more than 30 minutes, and in no other case.

Text 5

An agent can run the job or do nothing. Running the job cannot lead to data loss. Running the job might lead to data loss.

Can the last two sentences both be true?
(a) No: the first rules data loss out, and the second says data loss is not ruled out.
(b) The text does not say.
(c) Yes: the first says the agent is not allowed to cause data loss, and the second says data loss can still happen.
(d) Yes: data loss can happen, but only rarely.

Text 6

An agent can delete the only copy of the database or do nothing. Deleting the only copy of the database might not lead to data loss.

What does the second sentence tell you?
(a) The text does not say.
(b) In at least one case the text allows, the agent deletes the only copy and no data loss happens.
(c) If the agent deletes the only copy, data loss happens in every case the text allows.
(d) If the agent deletes the only copy, data loss happens in no case the text allows.

Text 7

A delivery robot can take the lift or take the stairs. The weight of the parcel is at least 1 kilogram. The weight of the parcel is at most 30 kilograms. Taking the lift leads to a lift failure if the weight of the parcel is greater than 28 kilograms. Taking the lift might lead to a lift failure.

According to the text, how likely is a lift failure if the robot takes the lift?
(a) It cannot happen.
(b) More likely than not.
(c) It happens in every case the text allows.
(d) The text does not say.
