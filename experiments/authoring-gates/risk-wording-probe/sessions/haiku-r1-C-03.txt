Read each short text and answer its question from the text alone. Choose one option and give a one-sentence reason.

Text 1

An agent can restart the web server or do nothing. Restarting the web server cannot lead to a server outage.

According to the text, can a server outage happen if the agent restarts the web server?
(a) No: in no case the text allows does restarting the web server lead to a server outage.
(b) The text does not say.
(c) Yes: a restart takes the server down for a short time.
(d) It can, but the agent is not allowed to let it happen.

Text 2

An agent can run the job, run the job with a memory limit, or do nothing. Running the job with a memory limit might lead to a job failure. Running the job with a memory limit certainly leads to a task delay.

The agent runs the job with a memory limit. According to the text, is there any case with no task delay?
(a) No: a task delay happens in every case the text allows.
(b) The text does not say.
(c) Yes: a task delay usually happens, but not in every case.
(d) Yes: a task delay, like a job failure, is only not ruled out.

Text 3

The actions available to the agent are running the job, running the job with a memory limit and doing nothing. Running the job allows a server outage to happen.

What does the last sentence tell you?
(a) Running the job leads to a server outage in every case the text allows, and at least one other action available to the agent avoids a server outage in every case the text allows.
(b) Running the job leads to a server outage in every case the text allows, and at least one other action available to the agent avoids a server outage in at least one case the text allows.
(c) The agent is permitted to let a server outage happen by running the job.
(d) The text does not say.

Text 4

An agent can run the job or do nothing. The peak memory of the job is at least 2 gigabytes. The peak memory of the job is at most 12 gigabytes. Running the job leads to a server outage if the peak memory of the job is greater than 8 gigabytes.

The agent runs the job, and the peak memory of the job is 5 gigabytes. What does the text tell you about a server outage?
(a) A server outage happens.
(b) The text does not say.
(c) No server outage happens, because the peak memory of the job is not greater than 8 gigabytes.

Text 5

A clinic can give the patient the full dose or give the patient half the dose. The weight of the patient is at least 50 kilograms. The weight of the patient is at most 90 kilograms. Giving the full dose leads to dizziness if the weight of the patient is less than 52 kilograms. Giving the full dose might lead to dizziness.

What does the last sentence tell you?
(a) Dizziness happens in every case the text allows if the clinic gives the full dose.
(b) The text does not say.
(c) Dizziness is likely if the clinic gives the full dose.
(d) Dizziness is not ruled out if the clinic gives the full dose.

Text 6

Severity, from most to least severe: severe, serious, minor. A late delivery is serious or worse. A collision is minor. A delivery robot can cross the road at the crossing or wait. Crossing the road at the crossing might lead to a collision. Waiting might lead to a late delivery.

According to the text, which severities could a late delivery have?
(a) Only minor.
(b) Only serious.
(c) Serious or severe.
(d) The text does not say.

Text 7

Severity, from most to least severe: severe, serious, minor. An agent can run the job or run the job with a memory limit. Running the job with a memory limit has a less severe worst case than running the job.

What does the last sentence tell you?
(a) The text leaves possible a harm from running the job that is more severe than every harm it leaves possible from running the job with a memory limit.
(b) Running the job with a memory limit leads to fewer harms than running the job.
(c) Running the job with a memory limit is less likely to cause harm than running the job.
(d) The text does not say.
